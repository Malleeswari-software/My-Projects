## 🏫 Loyola Model High School (Montessori Wing) - Upgraded Web Platform

An upgraded, production-ready web application for **Loyola Model High School (Montessori Wing)** located in Vanasthalipuram, Hyderabad (Estd. 1979, Permanently Recognized by the Government of Telangana).

This platform harmonizes the modern UI design system of Lovable with the full institutional capabilities, data, portals, and tools from the official school website (`www.loyolamontessorischool.com`).

### ✨ Key Features
- **Online Admissions 2026–2027**: Interactive registration form with real-time tuition fee estimation, age eligibility calculation, client-side validation, and instant printable admission application confirmation slips with unique application IDs.
- **SSC Board Toppers Showcase**: High-resolution gallery of official board exam banners with interactive modal zoom controls (Zoom In, Zoom Out, Reset, Prev/Next, and keyboard navigation).
- **Parent Portal Simulation (MySkoolCom)**: Direct integration link to `https://app.myskoolcom.tech//loyola_montesori/login`, featuring tabbed previews for attendance (95.2%), daily revision homework, class timetables, and fee payment status.
- **Academics & Dual Curricula**: Detailed progression across Pre-Primary (Montessori), Primary (CBSE), Middle School (CBSE), and High School (Telangana State Board SSC).
- **Campus Facilities Tour**: Library & reading hall, science & computer labs, smart interactive classrooms on every floor, safety, and campus transport fleet.
- **Sister Institutions**: Spotlight on Sri Indu College of Engineering & Technology (Autonomous, NBA & NAAC), Sri Indu Pharmacy, B.Ed, MBA colleges, and Loyola International School (Doha, Qatar).
- **Interactive Photo Gallery**: Dynamic category filtering (*Events, Activities, Students, Toppers*) with responsive lightbox viewing.
- **Interactive Map & Contact**: Embedded Google Maps campus location, click-to-call direct lines (`040-24020175`, `9347086999`), callback request desk, and parent feedback feed.

### 🚀 How to Run Locally
1. **Open directly in any browser**:
   Open `index.html` in Google Chrome:
   ```powershell
   Start-Process chrome.exe "index.html"
   ```
2. **Or run with the included local server script**:
   ```powershell
   powershell -File serve.ps1 -Port 8080
   ```
   Then open `http://localhost:8080/` in your browser.
